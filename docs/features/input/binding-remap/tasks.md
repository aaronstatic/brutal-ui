## Phase 1: The Listen, a Key Capture, the Commit, and the HelloPanel Rebind (16/16 complete)
**Goal:** `BeginRebind(action, scheme)` opens a listen inside `ReadFrame`, and the scan of `context.Input` commits the next fresh key press as the new binding of that action in that scheme. `RebindCancelKey` (Escape by default) cancels, and the listen consumes it. `CancelRebind` closes with no change. A suppressed frame writes no value, runs no command on all five paths, emits no release edge, and keeps the device track and `OnSchemeChanged` running. HelloPanel rebinds the `NavigateUp` key live through a button and shows the state in a seventh label.
